# התפריט שלי

אפליקציה אישית למעקב אחרי תפריט: צום בוקר, ארוחות, קלוריות חופשיות, העמסה שבועית והיסטוריה.

- עובדת בלי אינטרנט ונשמרת בטלפון בלבד (localStorage). שום נתון לא נשלח לשרת.
- גיבוי: לשונית "גיבוי", קובץ JSON. מומלץ כל מוצאי שבת.
- התקנה באנדרואיד: לפתוח את הקישור ב-Chrome, תפריט שלוש הנקודות, "התקנת אפליקציה" או "הוספה למסך הבית".

מבנה: `index.html` (כל האפליקציה בקובץ אחד), `manifest.webmanifest`, `sw.js` (עבודה בלי רשת), אייקונים.
